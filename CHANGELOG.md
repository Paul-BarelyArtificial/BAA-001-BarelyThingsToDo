# Changelog

## v1.0.0 - First Production Release

### Added

- Google Authentication
- Firebase Firestore cloud storage
- Cross-device task synchronisation
- Add task with optional notes
- Clear/delete task from Firestore
- Desktop drag-and-drop task ordering
- Mobile-friendly drag-and-drop task ordering using SortableJS
- Barely Artificial branding
- Dark responsive UI
- Progressive Web App basics
- Version footer
- Cache-busting for CSS and JavaScript

### Fixed

- Tasks no longer return after being cleared
- Task changes sync between desktop and mobile
- Mobile reordering now works properly
- Removed old local prototype footer text
- Replaced local-only task storage with Firestore-backed storage

### Notes

This release marks the first complete production-ready version of To Do Tomorrow.
